# Security Policy

If you believe that you've found a security vulnerability in this project,
please report it using GitHub's [private vulnerability reporting feature][reporting].
For **incorrect results** or other regular bugs, please open GitHub issues.

[reporting]: https://docs.github.com/en/code-security/how-tos/report-and-fix-vulnerabilities/report-privately

Please include enough detail in your report to reproduce the issue.
It is a goal to acknowledge receipt of all security reports within 72 hours,
but response times may vary due to factors outside of this project.
